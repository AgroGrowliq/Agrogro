AGROGROW WEBSITE — FIVE SEPARATE NAVIGATION PAGES

This package contains five separate HTML pages:
1. index.html — Home
2. about.html — About Us
3. products.html — Products / Services
4. resources.html — Blog / Resources (two educational articles)
5. contact.html — Contact Us

All pages share the same responsive header, green/cream design system and footer. Navigation links open separate files, not just page sections. The contact form is a front-end demo and requires a form service/backend before it can receive real enquiries. Email and Instagram are configured; phone and address remain placeholders. Product variants, pack sizes, crop suitability and other factual product details must be verified before launch.

Google Fonts and Tailwind CDN are referenced in the page head where used; shared CSS is embedded in each page so the core layout and navigation still render without Tailwind. A network connection is needed for remote fonts.
